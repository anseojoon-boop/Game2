# 인관심 7조 과제

첫 소개팅 장면을 플레이할 수 있는 비주얼 노벨 프로토타입입니다. 시작 화면에서 **새로 시작**을 누르면 성별을 고르고, **로드**를 누르면 저장한 장면으로 돌아갑니다. **본인 성별을 남성으로 고르면 여성 상대**, **여성으로 고르면 남성 상대**가 카페에 나옵니다. 상대 이름은 둘 다 `이름 미정`입니다. 두 번째 장면은 아직 만들지 않았습니다.

## 플레이 방법

웹 미리보기(현재 버전 고정): https://raw.githack.com/anseojoon-boop/Game2/e31d822cdd16ec1df48813788a78379e25f54cc4/index.html

`main`을 사용하는 미리보기 주소는 중간 서비스의 캐시 때문에 예전 화면이 나올 수 있습니다. 위 주소는 카페 첫 소개팅 장면이 들어 있는 커밋을 직접 가리킵니다. 이후 게임 내용을 수정하면 새 커밋 주소로 바꾸거나 아래 GitHub Pages 주소를 사용하세요.

대사창의 **다음**을 눌러 진행합니다. A·B·C·D 선택지에는 아직 설명 문장이 없지만, 고른 알파벳에 따라 호감도가 변합니다. 현재 설정은 **A +2, B +1, C -1, D -2**이며, 두 번 선택할 수 있습니다. 오른쪽 위 게이지는 가운데가 0이고, 양쪽에 10칸씩 있습니다. **한 칸은 호감도 1**이며, 오르면 오른쪽 분홍색, 내려가면 왼쪽 파란색으로 채워집니다. 호감도 범위는 −10부터 +10까지입니다. **저장**과 **불러오기**는 현재 장면·성별·호감도를 같은 브라우저에 기록합니다. **처음부터**를 누르면 성별 선택으로 돌아갑니다.

## 직접 수정하는 방법

1. GitHub에서 `story.js`를 엽니다: https://github.com/anseojoon-boop/Game2/edit/main/story.js
2. 대사를 바꾸려면 `nodes` 안에서 원하는 장면의 `text: "..."` 부분만 수정합니다.
3. 상대 이름을 정하면 `partners`의 `female`과 `male`에 있는 `name: "이름 미정"`을 바꿉니다.
4. 선택지 문장을 정하면 `first_choice`와 `second_choice`의 `label: "A"` 같은 부분을 문장으로 바꿉니다. 호감도 점수는 같은 줄의 `affection` 숫자로 바꿀 수 있습니다. 양수는 상승, 음수는 하락입니다.
5. GitHub의 **Commit changes**를 누르면 변경 내용이 저장소에 반영됩니다. 따옴표, 쉼표, 중괄호는 그대로 두세요.

시작 화면 배경은 `assets/title-cafe.png`, 게임 카페 배경은 낮 시안(`assets/concepts/cafe-day.png`)입니다. 저녁·비 오는 날 시안도 같은 폴더에 남아 있습니다. 상대 그림은 성별을 구분하는 임시 픽토그램입니다. 실제 그림으로 교체하려면 `assets` 폴더에 이미지 파일을 올리고, `story.js` 맨 위의 `assets`에서 파일 경로를 바꿉니다. PNG·JPG·SVG를 사용할 수 있습니다. 시작 화면의 로고·버튼 글자는 `index.html`, 화면 색과 크기는 `style.css`, 진행 기능은 `game.js`에 있습니다.

파일을 직접 실행하려면 `index.html`을 브라우저에서 엽니다. 브라우저가 로컬 파일 열기를 막는 경우 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 엽니다.

고정된 GitHub Pages 주소를 만들려면 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택해 저장하세요. 게시 후 주소는 https://anseojoon-boop.github.io/Game2/ 입니다.
