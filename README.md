# 인관심 7조 과제

첫 소개팅 장면을 플레이할 수 있는 비주얼 노벨 프로토타입입니다. 시작 화면에서 **새로 시작**을 누르면 성별을 고르고, **로드**를 누르면 저장한 장면으로 돌아갑니다. **본인 성별을 남성으로 고르면 여성 상대**, **여성으로 고르면 남성 상대**가 카페에 나옵니다. 상대 이름은 둘 다 `이름 미정`입니다. 현재 대사는 `예시 대화 1`부터 `예시 대화 14`까지 자리표시 문구이며, 두 번째 장면은 아직 만들지 않았습니다.

## 플레이 방법

게임 주소(최신 `main` 배포): https://anseojoon-boop.github.io/Game2/

`story.js`를 수정하고 GitHub에서 **Commit changes**를 누르면 Pages가 새 버전을 게시합니다. 게시까지 몇 분 걸릴 수 있습니다. 예전 대사가 보이면 브라우저에서 **Ctrl+Shift+R**로 새로고침하고, GitHub 저장소의 **Actions**에서 `pages build and deployment`가 완료됐는지 확인하세요. 주소에 긴 영문·숫자 커밋 번호가 들어간 `raw.githack.com` 링크는 해당 버전에 고정되므로 이후 수정 내용이 반영되지 않습니다.

대사창의 **다음**을 눌러 진행합니다. 예시 대사 두 줄마다 A·B·C·D 선택지가 한 번씩 나오며, 총 일곱 번 선택합니다. 선택지는 나중에 문장을 넣을 수 있도록 사각형 네 칸으로 배치했습니다. 현재 설정은 매 선택마다 **A +2, B +1, C -1, D -2**입니다. 오른쪽 위 게이지는 가운데가 0이고, 양쪽에 10칸씩 있습니다. **한 칸은 호감도 1**이며, 오르면 오른쪽 분홍색, 내려가면 왼쪽 파란색으로 채워집니다. 호감도 범위는 −10부터 +10까지입니다. 선택 후 호감도가 **−8 이하**가 되면 즉시 게임 오버 화면이 나옵니다. 첫 번째 장면을 마치면 호감도 **8 이상** 여부에 따라 다음 장면 준비 중 안내가 나옵니다. 두 번째 장면은 아직 구현하지 않았습니다. **저장**과 **불러오기**는 현재 장면·성별·호감도를 같은 브라우저에 기록합니다. 진행 중 **시작 화면**을 누르면 메뉴로 돌아가며, 저장하지 않은 진행 상태는 다시 불러올 수 없습니다.

## 팀원과 공유하기

위 게임 주소를 팀원에게 보내면 됩니다. 주소를 열어 플레이하는 것만으로는 내 GitHub 계정에 로그인하거나 저장소를 수정할 권한이 생기지 않습니다. 이후 대사를 수정해 배포해도 게임 주소는 같습니다.

저장 기록은 서버나 GitHub 계정이 아닌 **플레이한 사람의 브라우저 저장 공간(localStorage)**에 남습니다. 서로 다른 기기나 브라우저 프로필을 쓰는 팀원에게 내 기록이 전달되지 않습니다. 같은 기기에서 같은 브라우저 프로필을 함께 쓰면 그 기록은 보일 수 있습니다.

## 직접 수정하는 방법

1. GitHub에서 `story.js`를 엽니다: https://github.com/anseojoon-boop/Game2/edit/main/story.js
2. 대사를 바꾸려면 `nodes` 안에서 원하는 장면의 `text: "..."` 부분만 수정합니다.
3. 상대 이름을 정하면 `partners`의 `female`과 `male`에 있는 `name: "이름 미정"`을 바꿉니다.
4. 선택지 문장을 정하면 `first_choice`부터 `seventh_choice`까지의 `label: "A"` 같은 부분을 문장으로 바꿉니다. 호감도 점수는 같은 줄의 `affection` 숫자로 바꿀 수 있습니다. 양수는 상승, 음수는 하락입니다.
5. 게임 오버 기준은 `gameOver.threshold`, 다음 장면 안내 기준은 `first_scene_end.nextScene.minAffection`에서 바꿀 수 있습니다.
6. GitHub의 **Commit changes**를 누르면 변경 내용이 저장소에 반영됩니다. 따옴표, 쉼표, 중괄호는 그대로 두세요.

시작 화면 배경은 `assets/title-cafe.png`, 게임 카페 배경은 낮 시안(`assets/concepts/cafe-day.png`)입니다. 저녁·비 오는 날 시안도 같은 폴더에 남아 있습니다. 상대 그림은 성별을 구분하는 임시 픽토그램입니다. 실제 그림으로 교체하려면 `assets` 폴더에 이미지 파일을 올리고, `story.js` 맨 위의 `assets`에서 파일 경로를 바꿉니다. PNG·JPG·SVG를 사용할 수 있습니다. 시작 화면의 로고·버튼 글자는 `index.html`, 화면 색과 크기는 `style.css`, 진행 기능은 `game.js`에 있습니다.

파일을 직접 실행하려면 `index.html`을 브라우저에서 엽니다. 브라우저가 로컬 파일 열기를 막는 경우 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 엽니다.

게임 주소가 열리지 않으면 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**가 선택됐는지 확인하세요.
